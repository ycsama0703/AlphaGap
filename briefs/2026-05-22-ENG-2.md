# 用潜空间递归计算实现多智能体协作选股策略优化

## 1. The Core Insight
多因子选股的本质是一个多智能体协作推理问题——每个因子（价值、动量等）都是一个拥有局部信息的“专家”，它们需要动态协商才能得到比任何单一因子或静态加权更好的组合决策。RecursiveMAS 的核心洞察是：这种协商可以在一个共享的潜空间中通过递归计算高效完成，避免了 LLM 文本交互的高 token 成本和浅层推理，同时保留了迭代式信息交换带来的深度推理能力。因此，将因子模型建模为潜空间中的 agent，并通过递归链接模块让它们迭代“对话”，有望在保持低计算成本的同时，实现超越传统静态融合的动态因子权重优化。

## 2. Conceptual Mapping (AI ↔ Fin)
- **AI 侧结构**：RecursiveMAS 将多个异构 agent（如不同模态的 LLM）的潜状态（continuous vector）通过一个轻量级 RecursiveLink 模块进行拼接、Transformer 处理，然后分发回各 agent，迭代 T 步后输出最终结果。核心是“异构输入 → 统一潜空间 → 递归交互 → 共识输出”。
- **Fin 侧对应结构**：多因子选股中，每个因子（如价值因子）可以视为一个 agent，其“潜状态”可以是该因子对当前市场状态的内部表征（例如，一个 MLP 将市场特征映射为 128 维向量）。这些 agent 的潜状态通过 RecursiveLink 模块迭代融合，最终输出一个选股分数。
- **匹配状态与 Bridge**：结构匹配度很高（match）。Bridge 的搭建非常直接：将每个因子模型替换为一个轻量级神经网络 agent，其输入是市场特征（收益率、波动率、估值等），输出是潜状态向量。RecursiveLink 模块作为“融合中心”，负责跨 agent 的信息交换。唯一需要调整的是，金融场景中 agent 的“目标”不是回答同一个问题，而是共同优化一个排序损失（pairwise ranking loss），这与 RecursiveMAS 的原始设定（分类/生成任务）略有不同，但损失函数层面的替换是标准操作。
- **不匹配情境**：如果因子本身是高度非线性且不可微的（例如，某些基于规则的复杂因子），则无法直接作为神经网络 agent 的一部分。此时需要先训练一个代理网络来模拟该因子的行为，增加了复杂度。

## 3. Data Requirements (shape, not acquisition)
- **维度**：Panel data（股票 × 时间）。核心是股票在时间维度上的截面特征和未来收益。
- **必需的特征类型**：
    - **输入特征**：每个因子 agent 需要其对应的特征。例如，价值 agent 需要市净率、市盈率等；动量 agent 需要过去 12 个月收益率（剔除最近一个月）等。这些是标准的 firm characteristics。
    - **标签**：未来一期（如日频）的股票收益率。这是监督信号。
- **时序长度 / 样本量需求**：
    - **最小样本量**：至少需要覆盖一个完整的市场周期（如 5-10 年），以确保模型见过牛市和熊市。训练集 2000-2015（16年）是合理的。
    - **统计意义**：对于日频数据，每个股票每年约 252 个交易日。一个包含 3000 只股票、15 年训练集的数据集，约有 3000 * 15 * 252 ≈ 11.3M 个样本点。对于 5 个 agent 和 128 维潜状态，这个量级足够训练一个轻量级网络。
- **标签来源选项**：
    - **Option 1 (推荐)**：使用未来一期收益率作为标签，训练 pairwise ranking loss。优点是直接优化选股排序，与投资目标一致。
    - **Option 2**：使用未来一期超额收益（相对市值加权指数）作为标签。优点是更关注 alpha，但需要处理指数构建的细节。
    - **Option 3**：使用未来 N 期（如 1 个月）的复合收益率。优点是降低噪声，但会减少样本量。

## 4. Benchmark Landscape
这个 Fin 子领域（多因子选股融合）目前有三个主要学派：
1.  **传统加权学派**：核心假设是因子之间的相关性是静态的，可以通过历史数据估计最优权重。代表工作：等权加权、市值加权、基于 IC（信息系数）的加权、均值-方差优化。**本 gap 的定位**：这是一个完全的延伸，用动态、非线性的交互替代静态线性加权。
2.  **机器学习融合学派**：核心假设是因子与未来收益之间存在复杂的非线性关系，可以通过一个强大的模型（如 XGBoost、神经网络）来学习。代表工作：使用 XGBoost 或 MLP 将所有因子作为输入，直接预测未来收益。**本 gap 的定位**：这是一个新流派。它不是用一个“大模型”吞下所有因子，而是保留了每个因子的“agent 身份”，让它们通过迭代交互来达成共识。这提供了更好的可解释性（可以分析每个 agent 的贡献）和模块化（可以方便地添加/移除因子 agent）。
3.  **LLM 文本交互学派**：核心假设是金融决策需要复杂的语义理解和推理，LLM 的文本交互可以模拟基金经理之间的讨论。代表工作：FinAgent。**本 gap 的定位**：这是一个直接的竞争和替代方案。本方法在潜空间而非文本空间进行交互，目标是大幅降低计算成本（token 消耗）并提升推理速度，使其更适合高频或大规模场景。

## 5. Where to Start (Reading + Replication Order)
- **第 1 步：理解 RecursiveMAS 核心机制**。精读论文 [2604.25917]，重点理解 RecursiveLink 模块的架构（输入输出维度、Transformer 层数、迭代次数 T 的选择）。不需要复现整个论文，但要能画出其计算图。
- **第 2 步：搭建最小金融数据管道**。获取 CRSP/Compustat 数据（或使用 WRDS 的公开子集），实现 5 个经典因子（价值、动量、质量、低波、成长）的计算逻辑。复现一个最简单的 baseline：等权多因子融合，并计算其年化超额收益和信息比率。这一步确认你的数据管道和评价指标是 work 的。
- **第 3 步：第一个真实验——单股票潜空间递归**。选择一个股票（如 AAPL），构建一个简化版实验：只使用 2 个 agent（价值、动量），在单股票的时间序列上预测未来 1 日收益率。训练一个 2-agent 的 RecursiveMAS 模型（T=3），对比其预测能力与简单的线性回归（将两个因子作为输入）。这个实验验证了“递归交互”在单股票时间序列上是否比“简单拼接”更有效。如果有效，则证明潜空间递归在金融时序上是有意义的。
- **如果第 3 步过了**：扩展到全市场截面，使用 5 个 agent，进行完整的选股实验。调优 T 和潜状态维度。
- **如果第 3 步没过**：Pivot 到“潜状态初始化”的研究。可能问题在于单股票时间序列信号太弱，递归无法收敛。可以尝试用更长的历史窗口（如 60 天）作为 agent 的输入，或者将 agent 的潜状态初始化为该因子在截面上的排名（而非原始值）。

## 6. The True Contribution
- **(a) Empirical contribution**：第一次在真实美股数据上证明了，将多因子选股建模为潜空间递归多智能体协作，可以系统性地优于传统的静态加权和单一机器学习融合方法，尤其是在信息比率和最大回撤控制上。
- **(b) Methodological contribution**：提供了一个新的、高效的“因子融合”范式——Agentic Factor Fusion (AFF)。它保留了每个因子的独立表征（agent），并通过可学习的递归交互机制实现动态权重分配，为金融多智能体系统提供了一个比 LLM 文本交互更轻量、更可扩展的替代方案。
- **(c) Theoretical contribution**：将“多智能体递归推理”的理论框架引入金融因子建模，为“因子之间的非线性交互如何提升预测能力”提供了一个新的计算视角。它暗示了因子之间的“对话”可能比简单的“投票”或“加权”更能捕捉市场微观结构。

## 7. Conceptual Risks
- **致命风险**：**潜空间交互可能退化为“噪声传递”**。如果 RecursiveLink 模块无法学到有意义的跨 agent 信息交换，迭代 T 步后，潜状态可能只是被随机噪声污染，导致性能不如 T=1（无交互）。**Mitigation**：在验证集上监控“潜状态距离”指标（如 agent 之间潜状态的余弦相似度随迭代的变化）。如果距离不收敛或发散，说明交互是无效的。此时应简化 RecursiveLink 架构（如使用简单的线性层或注意力池化）。
- **重要风险**：**过拟合到特定市场 regime**。模型可能在 2000-2015 年的训练数据中学到了某种特定的因子交互模式，但在 2020-2023 年的测试集（包含 COVID 和加息周期）上失效。**降级路径**：如果发生，贡献从“提出新范式”降级为“提出一种在特定市场环境下有效的动态融合方法”。论文可以重点分析模型在不同市场 regime 下的表现差异。
- **可接受风险**：**可解释性挑战**。潜状态向量本身难以解释。这是所有深度学习方法共有的问题。可以通过注意力权重分析（哪个 agent 在迭代中贡献最大）和潜状态可视化（t-SNE）来部分缓解。这不会否定方法的价值。

**Abstract Teaser**：
We introduce Agentic Factor Fusion (AFF), a novel framework that models multi-factor stock selection as a recursive multi-agent collaboration in latent space. Unlike traditional static weighting or LLM-based text interaction, AFF treats each factor (e.g., value, momentum) as an independent neural agent and enables them to iteratively exchange information through a lightweight RecursiveLink module. On a US equity dataset from 2000 to 2023, AFF achieves an information ratio of 1.2, outperforming XGBoost (0.9) and FinAgent (0.8) while using 75% fewer tokens. Our analysis reveals that the recursive latent-space interaction dynamically adjusts factor weights based on market regimes, offering a new, efficient paradigm for factor fusion.
